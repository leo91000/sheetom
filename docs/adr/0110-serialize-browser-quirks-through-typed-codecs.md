# Serialize browser quirks through typed codecs

Standard typed values use Vendored Lightning Source serialization, while each measured Chromium text divergence is owned by an Observable Codec selected by semantic value family. Observable Codecs inspect Semantic Property Values and Recovered Component Value Trees and cannot patch, split or reparse an intermediate serialized string. Reparsable Stylesheet Serialization remains a distinct structured traversal so a CSSOM quirk cannot leak malformed syntax into the final stylesheet.
