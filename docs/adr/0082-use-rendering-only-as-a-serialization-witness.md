# Use rendering only as a serialization witness

Computed style remains outside the Authoring CSSOM and SheetOM will not expose cascade, layout, or rendering APIs. Differential serialization tests first compare identical mutations through SheetOM and native Authoring CSSOM adapters, then attach the reparsable SheetOM output to a fresh native sheet and compare its observable rule tree plus selected computed longhands. Those Rendering Witnesses detect semantic regressions such as shorthand state resurrection without becoming a public SheetOM capability. Exhaustive shorthand state checks remain non-rendering; RC4 targets witnesses at the eight high-risk families `background`, `mask`, `border-image`, grid, font, animation, transition, and offset.
