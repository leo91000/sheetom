# Require versioned grammar instead of literal exceptions

RC6 support is established by the complete Versioned Grammar Inventory for its pinned Chromium baseline, combining specification productions, browser manifests, applicable WPT, relevant Chromium tests, generated oracle probes, and reviewed prose-defined branches. A Chromium-accepted branch missing from vendored Lightning CSS must be implemented as a general grammar correction in Lightning or the Rust CSS Engine; exact-value allowlists may exist only temporarily during shadow migration and are forbidden from RC6 runtime artifacts.
