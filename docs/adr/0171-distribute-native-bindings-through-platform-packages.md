# Distribute native bindings through platform packages

SheetOM will replace its roughly 91 MB unpacked universal native tarball with a small root package and one public `@sheetom/native-<target>` optional npm package per native target, while retaining the established unscoped `sheetom` root. All packages share the exact SheetOM version: release tooling publishes and verifies every required platform package before publishing the root package, while Changesets treats the platform packages as synchronized implementation artifacts without independent changelogs. A target is published and described as supported only after CI executes those exact bytes in a matching Node.js environment; accepted Rust or Node-API target triples are insufficient evidence. The existing eight targets remain required, and RC7 additionally attempts Windows x86 plus GNU Linux ARMv7, ppc64le and s390x and musl Linux ARMv7. RC7 stops for explicit review rather than silently omitting any candidate that cannot be executed faithfully; AIX remains unpublished until an exact runtime test is available. Platform packages are installable implementation artifacts rather than independent consumer APIs. The loader remains fail-fast, names the expected package and detected target, verifies the Engine ABI Identity, performs no install-time download or compilation, accepts no binary-path override, and never falls back to another engine. npm runs across the complete platform matrix, while pinned pnpm, Yarn Plug'n'Play and node-modules modes, Bun and Deno verify optional-package semantics on Linux x64, including cross-platform lockfiles and an intentional `--omit=optional` failure. Every immutable GitHub Release carries the exact root, WebAssembly and platform tarballs plus a manifest of their sizes, SHA-256 hashes and npm integrities. Structural gates prohibit binaries in the root, require exactly one matching binary per backend package, and block unexplained growth only when it exceeds both ten percent and 256 KiB. Native optimization remains on pinned stable Rust, reports pinned `cargo-bloat` evidence and measured profile variants, and may not weaken unwind-based process safety, compatibility, runtime coverage, or materially regress the Publisher workload. This supersedes ADR 0104.
