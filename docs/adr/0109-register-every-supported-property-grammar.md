# Register every supported property grammar

A generated Property Grammar Registry maps every property in the pinned Chromium Supported Property Manifest to a standard Lightning grammar or a typed SheetOM browser extension, and release validation requires exact equality between those sets. Grammar implementations consume a cssparser Parser entirely and cannot infer token kind, nesting or function identity from raw strings; only the Value Gate receives declaration text. A CI architecture check rejects the former text helpers in grammar modules while allowing name-prefix classification and final formatting where those operations are semantic.
