# Reprobe shorthand branches for release evidence

Every RC5-or-later release will re-execute the reviewed shorthand breadth and Grammar Branch Cases against the pinned Chromium Engine Oracle before publication. The Compatibility Report records the corpus and branch-model hashes, case counts, adapter outcomes, and any failing IDs, while targeted Firefox and WebKit observations continue to document engine divergences without duplicating the complete Chromium matrix. The generator's check mode only re-probes and fails on drift; its explicit recording mode is the sole path that may update observations, and neither mode invents or removes contract branches. Ordinary CI compares checked-in evidence without silently regenerating it; only the explicit release recording workflow may refresh immutable browser observations.
