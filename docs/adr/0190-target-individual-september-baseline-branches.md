# Target individual September Baseline branches

The dated authoring target advances to 2026-09-09. Select eligible individual
WebDX compatibility keys even when their family is not wholly Baseline. The
pinned web-features 3.37.0 snapshot remains unchanged. This admits 328 families
with 2,648 eligible authoring key records mapped to 603 executable surfaces;
1,107 entries concern DOM/evaluation and 475 remain deferred.

Sibling and progress functions belong to the typed calculation tree. Contextual
time and angle calculations must survive parsing and serialization rather than
being coerced to scalar values. Position-try descriptor restrictions belong to
shared declaration state so the two facades enforce identical mutation rules.

Chromium 151 remains the established authoring oracle. It predates the media
state selectors becoming Baseline, so those seven explicitly marked probes and
their support queries use Firefox 153 as the positive reference. This is a
documented per-surface resolution; it does not silently update existing browser
observations. The newer experimental progress no-clamp option is outside this
Baseline addition. Equal-endpoint progress serialization follows the pinned
browser contract; newer draft evaluation rules are not a rendering promise.

current contract and validation commands are in
[the September evidence document](../css-september-2026-parity-evidence.md).
