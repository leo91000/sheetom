# Migrate the CSS engine through shadow evidence

The incumbent and replacement Rust value paths may coexist only behind test-only internal seams while migration is underway; no public property-by-property rollout may create two runtime authorities. Shadow Engine Runs apply identical operations and compare complete browser-facing declaration state plus reparsable output. Independently tested lexical, grammar and serialization foundations may merge incrementally while remaining unreachable from the published interface, but the replacement becomes authoritative only after every difference is resolved and the old path is then removed without a runtime fallback. RC6 treats known observable differences in getters, `cssText`, item order, priority, atomicity or mutation sequences as release blockers even when rendering is equivalent.
