# Separate grammar-branch evidence from runtime authority

SheetOM will measure shorthand depth through finite, reviewed Grammar Branch Contracts while continuing to require exhaustive property breadth over the pinned Chromium manifest. Every property retains a breadth case and standard mutation, while grammar depth and structural mutations are shared by Shorthand Codec Profile unless a property adds a distinct branch. The multi-case Shorthand Capability Corpus remains published conformance evidence only: runtime acceptance comes from general parsers, named family validators, or a small separately reviewed Measured Literal Override table, and literal overrides never count as grammar-branch coverage. The build excludes compatibility evidence from the runtime graph and flags redundant overrides, avoiding circular tests and duplicated bundle weight at the cost of explicitly maintaining the few parser gaps that remain.
