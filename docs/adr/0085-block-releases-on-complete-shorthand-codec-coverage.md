# Block releases on complete shorthand codec coverage

The Shorthand Coverage Gate will block a release whenever a multi-longhand property in the Supported Property Manifest lacks a codec or an accepted static value cannot be expanded completely. Each manifested shorthand requires measured atomic expansion and synthesis coverage; the full mutation matrix runs for every codec shape and the eight known high-risk families, with Chromium Rendering Witnesses for their visual regressions and structured Authoring CSSOM observations from every available release engine.
