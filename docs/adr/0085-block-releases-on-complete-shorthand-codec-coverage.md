# Block releases on complete shorthand codec coverage

The Shorthand Coverage Gate will block a release whenever a multi-longhand property in the Supported Property Manifest lacks a codec, an applicable Grammar Branch Contract is incomplete, or an accepted static value cannot be expanded completely. Every manifested shorthand requires a pinned, non-CSS-wide breadth case and standard mutation, while every registered Shorthand Codec Profile requires exact positive, negative, and structural-mutation evidence for its reviewed branches. CSS-wide keywords and Measured Literal Overrides do not count as grammar coverage. The gate requires exact equality between manifested properties, registered definitions, breadth cases, required branches, and executed scenarios; a generic fallback, percentage threshold, or documented exclusion for a Chromium-positive case cannot satisfy that equality. The checked-in corpus records its Chromium version and manifest hash, uses explicitly generated browser observations plus reviewed manual cases, and never changes during ordinary CI. Chromium Authoring Roundtrip Witnesses cover every positive branch, Rendering Witnesses remain targeted at known high-risk families, and selected Operation Fixtures retain significant cross-engine divergences without duplicating the corpus. All codec profiles and branch evidence remain private implementation and conformance details rather than new public APIs.
