# Block releases on complete shorthand codec coverage

The Shorthand Coverage Gate will block a release whenever a multi-longhand property in the Supported Property Manifest lacks a codec or an accepted static value cannot be expanded completely. Every manifested shorthand requires a pinned, non-CSS-wide case in the Shorthand Capability Corpus whose Chromium 151 observations prove acceptance, ordered longhand expansion, synthesis, mutation atomicity, and reparsable serialization. CSS-wide keywords do not count as codec coverage. The gate requires exact equality between manifested multi-longhand properties, registered definitions, corpus case IDs, and completely passing concrete cases; a generic fallback cannot satisfy that equality. The checked-in corpus records its Chromium version and manifest hash, uses explicitly generated browser observations plus reviewed manual exceptions, and never changes during ordinary CI. Deeper grammar-branch and mutation matrices run once per codec shape, while Chromium Rendering Witnesses remain targeted at the known high-risk families and structured Authoring CSSOM observations are retained from every available release engine.
