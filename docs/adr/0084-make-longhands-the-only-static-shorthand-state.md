# Make longhands the only static shorthand state

Every accepted static shorthand will be expanded atomically through a semantic Static Shorthand Codec into the declaration block's canonical longhand records; the original shorthand value will not remain as parallel state or provenance. List-valued longhands retain the browser-observable cardinality, while shorthand synthesis applies CSS list repetition only as a transient view instead of persisting invented duplicate values. Getters synthesize exclusively from observable longhand text, while reparsable serialization may use its paired recovered representation. Getters and serialization will synthesize a shorthand only from the current complete, compatible, same-priority longhand set, otherwise expose an empty shorthand and serialize individual longhands. Pending Shorthand Groups retain recovered original tokens only for mutations containing a genuinely deferred substitution, refining ADR 0029 so stale shorthand text can never reactivate removed state.
