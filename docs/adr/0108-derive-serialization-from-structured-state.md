# Derive serialization from structured state

Each accepted declaration is tokenized twice by the same Vendored CSS Syntax Source: a lossless pass records its Recovered Component Value Tree, and Lightning or a typed browser extension performs semantic parsing. Declaration state retains the Semantic Property Value and recovery evidence as its sole authority; CSSOM Surface Serialization and Reparsable Stylesheet Serialization are derived without reparsing and may be cached only as disposable views. Fully explicit typed values compact the redundant recovery tree after parsing while retaining the owned source and typed AST; custom token streams, substitutions and end-of-input recovery retain the full tree. This accepts a measured parsing cost to avoid an invasive observer fork across every Lightning grammar, subject to the Publisher Performance Regression Gate.
