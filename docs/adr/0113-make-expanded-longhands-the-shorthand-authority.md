# Make expanded longhands the shorthand authority

A static shorthand mutation is accepted only after every emitted longhand has been parsed into an owned Semantic Declaration. The ordered longhand records are the declaration-state authority; shorthand text is retained as a validated recovered component tree solely to reconstruct CSSOM shorthand observability while the group remains intact. Breaking a group never reactivates a parallel shorthand record, and style declarations cannot use the generic textual Codec storage. CSS-wide keywords and pending substitutions keep their dedicated semantic representations.
