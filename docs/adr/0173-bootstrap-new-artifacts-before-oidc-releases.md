# Bootstrap new artifacts before OIDC releases

The free public-only `@sheetom` npm organization will be claimed before implementation and own `@sheetom/wasm` plus every `@sheetom/native-<target>` implementation package, while the established unscoped root keeps its current ownership and working OIDC configuration through RC7. The new packages' first versions will be packed and verified in CI, submitted with explicit public access through one authenticated staged-publication session, and approved together with maintainer 2FA before their GitHub Actions trusted-publisher relationships are configured in bulk. Staged bootstrap artifacts are not advertised as a partial release, and subsequent releases use no long-lived npm write token: they publish and verify the exact lockstep-versioned platform and WASM artifacts through OIDC before the root `sheetom` package becomes visible. Before the first stable, `sheetom` and `@sheetom/wasm` keep `latest` and `next` on the active RC, native packages publish prereleases under `next`, and stable publication moves every package to `latest` and removes stale `next` tags without unpublishing historical exact versions. The new topology ships as RC7 after its exact registry artifacts pass the complete acceptance matrix without waiting seven nights; the first stable release then requires seven consecutive scheduled validations against that published topology.
