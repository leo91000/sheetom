# Retain semantic property values

Every accepted ordinary declaration retains an owned Semantic Property Value through mutation, shorthand expansion and both serialization contracts instead of collapsing validation into a canonical string that later code must parse again. A single Recovered Component Value Tree records lexical source spans and implicit end-of-input recovery, allowing CSSOM Surface Serialization to reproduce the pinned browser while Reparsable Stylesheet Serialization closes required structures. Existing string-driven grammar and shorthand work must be reaudited rather than merged merely because it improves a finite corpus.
