# Hold RC6 for production acceptance

RC6 will be published only after the complete Rust migration passes the upstream vendored parser suites, applicable CSS Syntax and WPT scenarios, exact Property Grammar Registry equality, positive and negative branch evidence, the Process Safety Contract, token-oriented fuzzing, subprocess crash tests, Observable Fidelity Gate, versioned Chromium grammar inventory, a fresh Pinned Browser Baseline, applicable cross-engine conformance, native reparsing, the median-based Publisher Performance Regression Gate, and seven consecutive scheduled validation runs. Every minimized parser or crash counterexample becomes immutable conformance evidence, and the replaced engine cannot be removed while any observable difference lacks an explicit Compatibility Resolution. Work may land through multiple internal pull requests, but no partial RC6 package will be published; compatibility is exhaustive for its named, versioned Authoring CSSOM baseline rather than an unverifiable promise about all future CSS.
