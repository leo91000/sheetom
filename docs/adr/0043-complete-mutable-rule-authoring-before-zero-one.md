# Complete mutable rule authoring before 0.1

Version 0.1 will specialize every standards-defined rule that exposes mutable declarations, descriptors, media, or child-rule lists, including grouping, nested, keyframe, import, page, counter-style, and font-feature-value interfaces. Generic Rules remain only for read-only metadata rules and experimental or future rule types; this supersedes the earlier prototype-sized surfaces in ADRs 0006 and 0034.
