# Generate dispatch from a reviewed Rust registry

One reviewed Rust Property Grammar Registry generates parser dispatch, codec metadata and manifest-exhaustiveness tests; Chromium observations remain independent conformance evidence and never generate runtime acceptance. Accepted values become immutable shared Semantic Declarations whose observable and reparsable strings may be memoized with write-once caches, while mutations replace declarations rather than invalidate multiple sources of truth. Internal parse failures retain structured categories for opt-in diagnostics but do not add exceptions or parsing methods to the public CSSOM interface.
