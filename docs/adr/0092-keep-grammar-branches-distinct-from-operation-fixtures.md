# Keep grammar branches distinct from operation fixtures

The 11 reported RC4 shorthand losses, their three systemic analogues, and future codec-depth examples live as permanent Grammar Branch Cases. Operation Fixtures cover one representative case for each significant semantic shape or cross-engine resolution, plus the reproducible animation, overscroll, and background CSSOM-surface regressions, rather than duplicating every corpus row. This keeps branch coverage data-driven while retaining shared-adapter evidence for observable API sequences and engine precedence decisions.
